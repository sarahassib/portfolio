# Portfolio Sara Hassib

Portfolio bilingue français / anglais avec light mode, dark mode, animations et espace admin local.

## Lancer le site

Ouvrir un serveur statique dans ce dossier, puis visiter `http://localhost:4173`.

## Images des projets

Placer les captures dans `assets/projects/` :

- `projet1.png`
- `projet2.png`
- `projet3.png`

## Admin

La page `admin.html` sauvegarde actuellement les modifications dans le navigateur. La connexion Supabase sera ajoutée avant le déploiement final.
